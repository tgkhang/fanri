# fanri

See your Terraform. A local-first tool that turns Terraform code into an interactive infrastructure diagram, with no cloud access and no telemetry.

> Status: early setup. The HCL parser is not wired up yet (P0 spike).

## Quick start

```bash
npm install
npm run dev          # open http://127.0.0.1:5173/?t=dev
```
